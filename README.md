# Расходник

Офлайн-учёт расходов и доходов для Android: кошельки в сумах и долларах, категории, переводы между кошельками (с обменом валюты), статистика по месяцам, бэкап через «Поделиться».

- Интерфейс: `app/src/main/assets/www/index.html`
- Обёртка: `MainActivity.java` (WebView + мост `Android.share` для бэкапа и CSV)
- Сборка: push в `main` → GitHub Actions → APK в Releases.

Данные хранятся только на телефоне. Бэкап — Настройки → Бэкап → Поделиться (например, в Telegram «Избранное»); восстановление — Настройки → Вставить.
